# Coseismic-Dislocation-Creep-and-Recrystallization-in-a-Shallow-Carbonate-Hosted-Active-Fault v1.0
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17946192.svg)](https://doi.org/10.5281/zenodo.17946192)


Matlab script for processing electron backscatter diffraction (EBSD) data.

We advise for the calculations to be performed in MATLAB R2024b and MTEX 5.11.2 or any available later versions.

For instructions on how to use the script, please refer to DOI 10.5281/zenodo.7023999.
